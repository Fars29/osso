# Osso UI — popup and options

Two static pages, vanilla TypeScript, no framework. `tokens.css` holds the palette (paper, ink, muted, line, the fade grey, marrow) with a dark override, plus the switch, slider and button primitives both pages share. All state comes through `messaging.ts`; the pages never read storage or call the API.

**Rules** (`rules.ts`, shared by both pages): the field under the popup's header reads *keep ___*, its placeholder walking through *prices · deadlines · allergens · what I have to do · names of people* every 3 s (it fades out before the next fades in, so it never jitters). Enter adds (a chip pops in 160 ms, reads `prices · …` until the page reports, then `prices · 3` settling in from a hair below, `· 0` in muted); Escape clears; `×` removes; a duplicate flashes the chip it duplicates; at 8 the field disables with "8 is plenty". The field is focused when the popup opens on a judged page. Rules save through `setSettings({ rules })`; the background broadcasts `rulesChanged` to the pages, and the popup polls the tab until every chip has its count. The options page shows the same list, without counts, under Behaviour.

**Popup states** (`data-state` on `<main>`): `done` — big count-up of sentences kept, "/ total", the ink-over-grey bone bar, "judged in 0.9 s · ≈ $0.0012" or "from cache", page-kind chip; `judging`/`idle` — the sentence total, pulsing, over "sentences, judging…" (it counts down to the kept number when the judgment lands), polled every 500 ms; `no-key` — "Osso needs your TypeSafe key." with a marrow "Add key"; `invalid-key` — key rejected, "Fix key"; `disabled` — "Off on this site" (or "Osso is off" when the master switch is off); `skipped` — "Nothing to strip here" + reason; `error` — the reason on one line + "Retry" (reloads the tab); `cannot` — "Osso can't run here" on chrome:// and store tabs, or "Osso is waking up" when the background never answers. Controls: the site switch (`setHostEnabled` then `setEnabledHere`), the strictness slider (`setThreshold` to the tab on input, `setSettings` on change), "Reveal all"/"Fade again" beside "Hold ⇧ to peek" naming the configured key. The footer signs *Solo l'osso.* and links Settings. Spacing sits on an 8 px grid; the popup is about 470 px tall with two rules, well under Chrome's 600 px cap.

**Options sections**: Key (show/hide, Test → "Works · 0.3 s" or the error inline, Save, privacy note), Behaviour (enabled, default strictness, reveal key, animations), Sites (never/always textareas saved on blur, collapsible default deny list), Usage (six figures, Clear cache, Reset usage), About. Every save shows an inline "Saved" that fades. Without a background the page renders the defaults and says so once under the masthead.

**Preview**: `npm run build`, open `chrome://extensions`, enable Developer mode, "Load unpacked" → `dist/`. Click the toolbar icon for the popup; right-click it → Options for the settings page (or `chrome-extension://<id>/options.html`). Every state, light and dark, as pictures: `node --env-file=.env e2e/screens.mjs` writes them to `e2e/screenshots/screens/` (the popup states are seeded there, so no real page is needed). Unit tests: `npx vitest run test/ui.test.ts`.
